## Line numbers and highlights

```javascript config.js lines highlight={2-3}
const config = {
  retries: 3,
  timeout: 5000,
  verbose: false,
};
```

````mdx
```javascript config.js lines highlight={2-3}
```
````

| Option | Effect |
| --- | --- |
| `lines` | Shows line numbers |
| `highlight={2-3}` | Emphasises a line range |
| `focus={4}` | Dims everything except the given lines |
| `wrap` | Wraps long lines instead of scrolling |
| `expandable` | Collapses a long block behind a toggle |

## Multiple languages

`CodeGroup` renders one block per language with a tab for each. Each block needs a title.

<CodeGroup>

```bash cURL
curl https://api.example.com/v1/tasks \
  -H "Authorization: Bearer $BLAZE_API_KEY"
```

```javascript Node
const res = await fetch("https://api.example.com/v1/tasks", {
  headers: { Authorization: `Bearer ${process.env.BLAZE_API_KEY}` },
});
```

```python Python
import os, requests

requests.get(
    "https://api.example.com/v1/tasks",
    headers={"Authorization": f"Bearer {os.environ['BLAZE_API_KEY']}"},
)
```

</CodeGroup>

<Warning>
  Never paste a real key into an example. Read it from an environment variable, as above.
</Warning>
