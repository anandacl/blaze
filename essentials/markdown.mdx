## FrontmatterBB

Every page opens with a YAML block. `title` and `description` are the minimum; the rest is
optional.

```mdx
---
title: "Page title"
description: "One sentence shown under the title and in search results."
icon: "book"
sidebarTitle: "Shorter title"
---
```

| Field | Effect |
| --- | --- |
| `title` | Page heading and browser tab title |
| `description` | Subtitle, search result summary, and social preview text |
| `icon` | Icon in the sidebar and next to the title |
| `sidebarTitle` | Overrides `title` in the sidebar when the title is long |
| `mode` | `wide` hides the table of contents, `center` hides both sidebars |
| `noindex` | `true` keeps the page out of search engines |

## Text

```mdx
**Bold**, *italic*, ~~struck through~~, `inline code`, and [a link](/quickstart).
```

**Bold**, *italic*, ~~struck through~~, `inline code`, and [a link](/quickstart).

Use `##` for the sections of a page — `#` is reserved for the title set in frontmatter.
Headings up to `###` appear in the table of contents.
